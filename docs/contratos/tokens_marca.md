# Tokens de marca para el PDF del servidor

Para generar la carta responsiva sin abrir `DESIGN_SYSTEM.md`.

| Uso | Valor |
|---|---|
| Acento (unico) | `#FB670B` naranja GO |
| Texto principal | `#262626` |
| Texto secundario | `#535353` |
| Linea / borde | `#C5C5C5` |
| Fondo claro | `#FFFFFF` |
| Titulos | Blauer Nue (respaldo: Nunito, Poppins, Helvetica) |
| Cuerpo | Conthic (respaldo: Inter, Helvetica) |
| Folios y numeros de serie | JetBrains Mono (respaldo: Courier) |

El PDF va en tema claro siempre. Cero emojis. La razon social emisora sale de la tabla `empresa`, nunca hardcode.
